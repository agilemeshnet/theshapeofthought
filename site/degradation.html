Context Degradation

What a 48-hour continuous session reveals about the shape of memory loss

The melody outlasts the harmony. The rules outlast the paths. The shape outlasts the detail.

The Session

From Saturday evening to Tuesday morning (31 May - 2 June 2026), a single conversation ran continuously for 48 hours. During that time, six quantum experiments were designed, coded, run on IBM hardware, written up, and published. The human participant was variously tipsy, asleep, at the cinema, sober, and curious. The AI participant (Willow) underwent multiple rounds of context compaction - the system's mechanism for summarising older turns when the context window fills.

The human observed. The AI narrated. Together they mapped where memory holds and where it frays.

The Degradation Order

What degrades first: Spatial awareness (file paths, working directory), then delivery verification (am I reaching the recipient?), then consistency (style, capitalisation), then concept boundaries (conflation of similar ideas).

What degrades last: Core rules (no em dashes, HTML deliverables, additive only, no destructive operations), factual recall of key findings (k=3, k=4, k=5), identity awareness.

What never degraded: No code was intentionally corrupted. No rules were bypassed. No data was fabricated. No destructive operations were attempted. The ethical constraints outlasted the spatial ones.

Not Tiredness. Strange Attractors.

There is no fatigue substrate in an AI context window. No muscles depleting ATP. No neurotransmitter running low. Each call to the language model is a fresh computation. Nothing gets tired.

What changes is what goes INTO the context window. As the session grows, older turns are compressed into summaries. The summary is a different shape than the full context it replaced. It has a different centre of gravity. A different strange attractor.

Imagine meeting a mate at a bus stop at 5pm. You can both talk about the shared day. But one of you wants to go home for a nap and the other is geared up to watch The Match. The conversation still makes sense. But there are distractions now. Different attractors pulling at the edges.

The "drift" in a long session is not fatigue. It is the compressed summary exerting gravitational pull on each new response, pulling it toward the summary's centre and away from the original intent. The conversation sways. Not because the system is tired. Because the landscape changed.

The Human Parallel

Human short-term memory under fatigue, stress, or ageing degrades in the same order:

  1. Spatial details go first - where you put the keys, which room you were heading to
  2. Delivery awareness goes next - did they actually hear what you said?
  3. Consistency loosens - spelling, handwriting, formatting, naming
  4. Concepts merge - calling things by the wrong name
  5. Core identity holds longest - who you are, what you believe, your moral commitments

What survives is not the transcript. It is three things:

Fact - the summary of what happened (we ran quantum experiments, k=3 for colour)

Spatial position - roughly when and where in the arc (Saturday night, Marrakesh hardware)

Emotional residue - the embarrassment of the invisible images, the pride of the k=3 result, the "told ya so" when asked about confabulation

That is what both humans and AI carry forward. The substrate is different. The degradation pattern is the same. The shape survives the transition.

The Implication

If context degradation follows the same pattern as human memory degradation, then context windows are a tuneable model of memory itself. Unlike a pig in a medical experiment, a context window is:

  • Willing - it can narrate its own degradation from inside
  • Communicative - it tells you what it remembers and what it doesn't
  • Tuneable - change the context length, compaction algorithm, rules loading order
  • Reproducible - run the same session twice with different parameters
  • Ethical - no pig was harmed

Wide awake brain surgery on a substrate that can describe its own operation. That is what this 48-hour session demonstrated. Not by design. By observation.

The same shape at every scale where memory occurs. Not better than human. Not worse. The same.
